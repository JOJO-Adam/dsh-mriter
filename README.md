# dsh-mriter

> **一句话生成一首歌，不是创作，是抽奖。**
>
> Mriter 是人类深度参与的 AI 音乐制作工具：AI 给材料和可核对的事实，词、判断、决定始终在你。

**Mriter for DeepSeek Harness** —— 两个工具：歌词结构诊断、和弦走向稀有度。
引擎确定性运行，同样的输入永远同样的输出；每条结论标出处（实测 / 文献 / 工艺经验 / 未验）。

- 官网：<https://mriter.com>
- npm：`@jojonadam/dsh-mriter`

## 安装

```bash
dsh plugin --profile desktop add @jojonadam/dsh-mriter
```

装完重启 DSH，工具列表里出现两个：

| 工具 | 做什么 |
|---|---|
| `mriter_advice` | 歌词 → 八节报告（结构、断点、作曲方向、和声稀有度、风格、词堆、编曲、盲区） |
| `mriter_progression` | 和弦走向 → 在 1029 首中文流行语料里的稀有度与分位 |

## 我们不做的事

- **不一句话生成整首**。它给方向与材料，成品由你写。
- **不评价作品好坏**。「俗」是分布事实，不是判决——判断权在作者。
- **不联网**。引擎纯本地，零依赖，零请求。

## 这个仓库里没有的东西

- 引擎源码与判据细节
- 基准用的曲目数据（和弦谱与歌词摘录有版权，不在此仓）
